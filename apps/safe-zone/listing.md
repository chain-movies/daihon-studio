# 縦動画セーフゾーンチェッカー｜ショート・リール・TikTok の UI にテロップが隠れないか

**価格: 無料（制作相談・テロップ素材集への導線）**

## キャッチ
「せっかく入れたテロップが、いいねボタンの下に隠れていた」をなくす。縦動画の画像か動画を置くだけで、各プラットフォームのボタンや説明文に隠れる範囲を重ねて表示。全部に共通で隠れない「テロップ安全域」を枠で出します。

## 説明
■ できること
- 画像（PNG/JPG）か動画（MP4/MOV）をドロップ → 9:16 に中央合わせで表示。動画は再生・シーク・その瞬間で停止
- ショート／リール／TikTok 風／ストーリーズ の UI ゾーンを色分けで重ねる（複数同時 OK）
- 選んだプラットフォーム全部で隠れない「テロップ安全域」を点線枠で表示。左右上下の px も表示
- 3 分割グリッド、フィード用の 4:5・1:1 トリミング枠
- 書き出し: 確認用 PNG（映像＋ゾーン）／透過ガイド PNG（1080×1920・編集ソフトの最上位トラックに置く）／安全域の数値 CSV
- ファイルは外部に送信しません（ブラウザ内だけで処理）

■ こんな人に
- ショート動画・リールを自分で編集している人（テロップ・顔・ロゴの位置決め）
- 横動画をショートに流用している編集者（16:9 を中央に置いたときの余白と UI の関係が分かる）
- クライアントに「この位置なら隠れません」と見せたい制作会社

■ 使い方
1. index.html をブラウザで開く 2. 素材をドロップ 3. プラットフォームを選ぶ 4. 枠の中にテロップを収める／透過ガイドを書き出して編集ソフトに重ねる

■ 注意
ゾーンは一般的なスマホ表示をもとにした目安です。端末・アプリの更新・キャプションの長さで前後します。
