クーポン券メーカー（製品版）
============================
1. index.html をブラウザ（Chrome推奨）で開く
2. 右で 店名・特典・条件・有効期限・スタンプ文字 を入力
3. 面付け（名刺大×8／A6×4）・枚数・色・通し番号の開始を選ぶ
4. 「A4 で印刷 / PDF 保存」→ 切り取り線で切る。SNS 用は「正方形 PNG」

・通し番号は A4 の枚数分、連番で振られます（例: 3 枚 × 8 面 = No.001〜024）
・入力はこのブラウザの中（localStorage）にだけ保存され、外部には送信されません
