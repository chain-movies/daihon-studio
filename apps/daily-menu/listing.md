# 日替わりメニュー表メーカー｜週間メニューを A4 印刷と SNS 画像に

**価格: 無料デモ（3 日分・透かしあり）／ 製品版 ¥980（買い切り・7 日分・透かしなし）**

## キャッチ
「今週の日替わり、まだ貼ってない」をなくす。曜日ごとにメイン・副菜・価格を入れるだけで、店頭に貼る A4 の週間メニュー表と、SNS 用の正方形画像・縦長画像が同時にできます。来週は「翌週にコピー」で日付だけ進めて、変わる日だけ書き換え。

## 説明
■ できること
- 7 日分のメニュー入力（メイン／副菜・ご飯・汁／価格／kcal 任意）。チェックを外した日は「お休み」表示
- A4 縦の週間メニュー表をそのまま印刷・PDF 保存（店名・タイトル・期間・下のひとこと付き）
- SNS 用 PNG: 正方形 1080×1080（フィード）と 縦長 1080×1920（ストーリーズ）
- 色 6 種（朱・だいだい・深緑・藍・ブラウン・ワイン）
- CSV 保存／読込（表計算ソフトで作ってもよい）、「翌週にコピー」、ブラウザに自動保存
- 外部送信なし。ブラウザの中だけで完結

■ こんな人に
- 弁当店・惣菜店・定食屋・社員食堂（毎週の貼り紙と SNS 投稿を 1 回で済ませたい）
- カフェ・パン屋の「今週のランチ」告知
- 保育園・介護施設の給食献立表（印刷用）

■ 使い方
1. index.html をブラウザで開く 2. 店名・週の初日・各日のメニューを入力 3. 「A4 で印刷」か「PNG」ボタン

■ 注意
PNG の文字は端末の標準フォントで描画されます。印刷は Chrome 推奨（余白なし・A4）。
