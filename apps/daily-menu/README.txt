日替わりメニュー表メーカー（製品版）
======================================
1. index.html をブラウザ（Chrome推奨）で開く
2. 右で 店名・タイトル・週の初日・色 を選ぶ
3. 各日のメイン／副菜／価格（kcal は任意）を入力。休みの日はチェックを外す
4. 「A4 で印刷 / PDF 保存」で店頭用、「正方形 PNG」「縦長 PNG」で SNS 用
5. 来週は「翌週にコピー」→ 変わる日だけ書き換え

・CSV 保存／読込 で表計算ソフトとの行き来ができます（列: date, dow, open, main, side, price, kcal）
・入力はこのブラウザの中（localStorage）にだけ保存され、外部には送信されません
