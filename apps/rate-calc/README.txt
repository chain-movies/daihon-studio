動画編集 単価計算・時給見える化（製品版）
============================================
1. index.html をブラウザ（Chrome推奨）で開く
2. 右上の「目標時給」「月の稼働時間」を自分の数字にする（例: 5,000円・120h）
3. テンプレを選ぶ → 案件名・日付・見積額・経費・工程別の作業時間を入れて「案件を保存」
4. 一覧で 実質時給（緑=目標以上／黄=目標の7割以上／赤=それ未満）と 適正単価・差額 を確認
5. 上の「月」で絞り込み、「時給が低い順」に並べ替えると値上げ候補が分かります
6. 「CSV で保存」で表計算ソフトへ。「バックアップ」で JSON 保存、「復元」で読み込み

・実質時給 = （見積額 − 経費）÷ 合計時間
・適正単価 = 目標時給 × 合計時間 ＋ 経費（次回の見積の根拠）
・「修正が +3h 増えたら」は、修正が長引いた場合の時給の目安です
・データはこのブラウザの中（localStorage）にだけ保存され、外部には送信されません。別の PC に移すときはバックアップ→復元を使ってください
