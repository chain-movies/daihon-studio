# 台本→SRT 字幕分割｜貼るだけで「1秒4文字・1行16文字」の字幕ファイル

**価格: 無料デモ（30字幕まで）→ Pro ¥980（買い切り・無制限）**

## キャッチ
台本はあるのに、字幕の尺合わせに1時間。そんな作業を、貼り付けて3秒で終わらせる。
句読点と助詞の切れ目で自然に分割し、読み速度から表示時間を自動配分。Premiere / CapCut / DaVinci / YouTube にそのまま読み込める SRT を書き出します。

## 説明
■ できること
- 台本を貼るだけで、句点→読点→助詞の切れ目の順に自然な字幕に分割（カッコ内や英単語の途中では切らない）
- 1行の文字数（既定16）と行数（1〜2行）を指定。半角は0.5字として数える現場ルール
- 表示時間の決め方を2通り: 読み速度（4／5／6／7 文字/秒のプリセット）から自動、または総尺を指定して文字数比で配分
- 最短表示時間・字幕間の空き・開始オフセットを調整。7文字/秒を超える「読み切れない字幕」を警告
- 一覧で各字幕を直接手直し → そのまま書き出し
- SRT / CSV（No・開始・終了・文字）/ TXT（1行=1字幕。テロップメーカーの一括書き出しに貼れる）/ クリップボード
- 設定と台本はブラウザ内に自動保存。JSON で控えも残せる

■ こんな人に

- 文字起こしAIは持っているが、台本どおりの正確な字幕が欲しい
- CapCut や iPhone で編集していて SRT を読み込みたい
