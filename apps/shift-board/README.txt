シフト表メーカー（製品版）
==========================
1. index.html をブラウザ（Chrome推奨）で開く
2. 右で 店名・週の初日・色・休業日 を入力
3. スタッフを追加し、曜日ごとのセルに「9-17」「休」などを入力（空欄を「休」で埋めるボタンあり）
4. 「A4 横で印刷 / PDF 保存」で店用、「一人ずつの縦長 PNG」でスマホ配布用
5. 来週は「翌週にコピー」→ 変わる所だけ書き換え

・CSV 保存／読込 で表計算ソフトと行き来できます（1 行目: name, 日付×7）
・入力はこのブラウザの中（localStorage）にだけ保存され、外部には送信されません
