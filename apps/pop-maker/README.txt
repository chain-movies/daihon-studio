商品 POP メーカー（製品版）
============================
1. index.html をブラウザ（Chrome推奨）で開く
2. 右で サイズ（A6×4／A5×2）・色・税込／税抜 を選ぶ
3. 「＋ 商品を追加」で商品を入力（商品名と価格だけでも OK）
4. 「A4 で印刷 / PDF 保存」→ 切り取り線で切る
5. SNS 用は「各商品を正方形 PNG で保存」

・CSV 保存／読込 で表計算ソフトと行き来できます（列: category, name, copy, price, was, badge, note）
・入力はこのブラウザの中（localStorage）にだけ保存され、外部には送信されません
