BASE 商品ギャラリー画像ジェネレーター（社内ツール）
=====================================================
テロップパックを BASE に登録するときの商品画像（1280×1280 PNG ×7枚）を自動生成します。

1. index.html をブラウザ（Chrome推奨）で開く（リポジトリ内の telop/designs.js・renderer.js を読むので、
   リポジトリのフォルダ構成のまま開くか、GitHub Pages の /apps/base-gallery/ を使う）
2. パックを選び、価格・キャッチ・バンドル価格を確認して「生成」
3. 「PNG をまとめて ZIP でダウンロード」→ BASE の商品画像に 01 から順に登録

生成される画像
  01_cover     表紙（商品トップ。サンプル6枚＋価格・商用OK バッジ）
  02_designs   収録デザイン一覧（全デザインを番号付きで）
  03_portrait  縦動画対応（9:16 サンプル4枚）
  04_howto     使い方3ステップ
  05_contents  同梱物
  06_compare   全パック比較表（この商品をハイライト、下にバンドル価格）
  07_faq       よくある質問・ライセンス

・デザインは telop/designs.js から直接描画するので、画像のアップロードは不要です
・フォントは Google Fonts から読み込みます（通信が必要）
・販売用アプリではないので DEMO フラグ・listing.md はありません
