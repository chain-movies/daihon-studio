BASE 商品ギャラリー画像ジェネレーター

社内ツール パックを選んで「生成」→ 1280×1280 PNG を BASE の商品画像にそのまま登録
右のパネルでパックを選び「生成」を押してください
1. 表紙（商品トップ）
2. デザイン一覧（全デザイン）
3. 縦動画対応（9:16 サンプル）
4. 使い方 3ステップ
5. 同梱物
6. 全パック比較表
7. FAQ・ライセンス
・デザインはこのリポジトリの telop/designs.js から直接描画します（画像のアップロード不要）。フォントは Google Fonts から読み込むので通信が必要です
・BASE の商品画像は正方形が崩れません。1枚目に「表紙」を置き、2枚目以降に一覧・使い方・比較表の順で登録してください
・価格・キャッチを変えたら再度「生成」を押してください
