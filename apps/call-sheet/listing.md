# 撮影 香盤表・タイムスケジュール ジェネレーター｜行を足すだけで時刻が揃う

**価格（推奨）: ¥1,480（買い切り）** ／ 見積書アプリとのセット ¥2,980

## キャッチ
Excel の香盤表で、1シーン延びるたびに時刻を全部打ち直していませんか？
所要時間を入れるだけで開始・終了が自動で並び、A4 横のタイムテーブルと「シーン×出演者」の香盤表を同じ入力から印刷できます。

## 説明
■ できること
- シーンを上から並べて所要時間を入力 → 開始・終了時刻を自動計算（休憩・移動も行として扱う）
- 1つの入力から2種類を切替: タイムテーブル（時刻・シーン・場所・出演者・スタッフ・機材・備考）／香盤表（シーン×出演者の●表）
- 出演者ごとの「入り〜終わり」、スタッフ・機材の一覧を自動集計
- テンプレート4種（会社紹介VP／インタビュー／イベント記録／ショートドラマ）から始められる
- A4 横で印刷・PDF 保存。CSV 書き出し（Excel・スプレッドシートで再編集可）、JSON 保存／読み込み
- ブラウザに自動保存。スマホでも閲覧可（現場で確認）

■ こんな人に
- フリーランスのディレクター・カメラマン、制作会社のAP
- 出演者・クライアントに「何時に来ればいいか」を毎回聞かれる人
- Excel テンプレの時刻ズレ・印刷崩れにうんざりしている人

■ 対応
Windows / Mac / iPad の Chrome・Edge・Safari。インストール不要・オフライン動作（フォント読み込みのみ通信）
