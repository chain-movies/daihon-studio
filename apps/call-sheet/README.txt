撮影 香盤表・タイムスケジュール ジェネレーター（製品版）
========================================================
1. index.html をブラウザ（Chrome推奨）で開く
2. 案件情報（作品名・撮影日・集合時刻・開始時刻・場所・連絡先）を入力
3. 「＋ シーンを追加」で行を足し、所要時間（分）・場所・出演者・スタッフ・機材を入力
   - 出演者などは「、」区切りで複数入力（例: 代表、社員A）
   - 休憩・移動は「＋ 休憩・移動を追加」
   - 開始・終了時刻は所要時間から自動で計算されます（並べ替えは ↑↓）
4. 上の切替で「タイムテーブル」「香盤表（シーン×出演者）」を選ぶ
5. 「PDF で保存 / 印刷」→ 印刷ダイアログで A4 横・PDF に保存

・テンプレート（会社紹介VP／インタビュー／イベント／ショートドラマ）から始めると早いです
・CSV は Excel・Google スプレッドシートでそのまま開けます。JSON は別PCでの読み込み用
・データはこのブラウザの中（localStorage）にだけ保存され、外部には送信されません
