# ナレーション尺計算・原稿タイマー｜文字数から秒数を速度別に

**価格: 無料デモ（先頭1,000字まで）／ Pro 版 ¥980（買い切り・文字数無制限）**

## キャッチ
「この原稿、何分になる？」を貼るだけで。ナレーション原稿を貼ると、読み上げ時間を「ゆっくり／標準／速め」の速度別に即計算。段落ごとの尺表と、目標尺に対して「あと何字削るか」まで出ます。

## 説明
■ できること
- 原稿を貼ると文字数（読む文字だけ。空白・記号除外、半角0.5字）と読み上げ時間を即計算
- 速度プリセット: ゆっくり 250字/分（企業VP）／標準 300／速め 350（YouTube）／早口 400（ショート）／カスタム
- 句読点の「間」を秒で加算（既定 0.3秒）
- 段落ごとの尺表（ゆっくり・標準・速め・累計）。CSV で保存、テキストでコピー
- 目標尺（例: 1分30秒）を入れると、過不足と「削る／足せる文字数の目安」を表示
- 字幕枚数の目安（1行16字×2行）。そのまま「台本→SRT 字幕分割」ツールへ
- 読み上げタイマー: 実際に読みながら計測 → 「実測の字/分」と計算値との差を表示（ナレーターの速度に合わせて調整）
- ブラウザに自動保存・外部送信なし

■ こんな人に
- 企業VP・CM・YouTube のナレーション原稿を書く人（尺に合わせて削る作業が毎回ある）
- ナレーター・声優（収録前に原稿の長さを把握したい）
- 動画編集者（原稿の段階で構成の尺配分を決めたい）

■ 使い方
1. index.html をブラウザで開く 2. 原稿を貼る 3. 速度と目標尺を選ぶ → 上の4つの数字と段落表を見る

■ 注意
計算値は目安です。ナレーターや口調で ±15% 程度ぶれるので、タイマーで実測して速度を合わせてください。
