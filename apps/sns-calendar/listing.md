# SNS 投稿カレンダー｜月間の投稿予定を媒体別に管理、CSV・ICS 出力

**価格: 無料デモ（当月の予定のみ）／ 製品版 ¥980（買い切り・全期間）**

## キャッチ
「今週、何をどこに投稿するんだっけ」をなくす。月間カレンダーに投稿予定（媒体・タイトル・素材の有無・担当）を置いて、週ごとの一覧と媒体別の本数を一目で確認。テンプレで一括配置、ICS でスマホのカレンダーに通知付きで登録できます。

## 説明
■ できること
- 月間カレンダーに投稿予定を追加（日付・時刻・媒体・タイトル・メモ・担当・素材の進み具合・投稿済み）
- 媒体ごとの色分け。Instagram / X / YouTube / TikTok / note / LINE は最初から入っていて、追加・色変更も自由
- 今月の本数・投稿済み・素材未着手・媒体別の本数をチップで表示。素材未着手は黄色で警告
- テンプレで一括配置: 週3投稿（月水金）／毎日ショート／企業アカウント標準（火木＋土）／新商品ローンチ（告知→当日→振り返り）
- 週別リスト表示（第1週〜、曜日・時刻・素材・担当・状態）。投稿済みの切替はワンクリック
- CSV（表計算へ）、ICS（スマホ・PC のカレンダーに読み込み。投稿の30分前に通知）、JSON バックアップ・復元、印刷（A4）
- ブラウザに自動保存・外部送信なし

■ こんな人に
- 中小企業の SNS 担当（1人で複数媒体を回している）
- 動画制作会社・フリーランス（クライアントの投稿予定を共有したい。CSV を渡すだけ）
- 店舗・教室（月初に投稿日を決めて、あとは素材を埋めるだけにしたい）

■ 使い方
1. index.html をブラウザで開く 2. テンプレで月の骨組みを配置 → 各予定をクリックしてタイトル・素材を埋める 3. ICS を書き出してカレンダーに登録

■ 注意
投稿そのものは行いません（予定管理のみ）。ICS の通知はカレンダーアプリ側の設定に従います。
