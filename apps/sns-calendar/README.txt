SNS 投稿カレンダー（製品版）
============================================
1. index.html をブラウザ（Chrome推奨）で開く
2. 右の「テンプレで一括配置」で月の骨組みを置く（週3投稿／毎日ショート／企業標準／ローンチ）
3. カレンダーの予定をクリックして、タイトル・メモ・担当・素材の進み具合を埋める
4. 日付のマスをクリックすると、その日付で新規追加できます
5. 上の「カレンダー／週別リスト」で表示切替。リストでは投稿済みをワンクリックで切替
6. 「CSV」で表計算へ、「ICS」でスマホ・PC のカレンダーに登録（投稿30分前に通知）
7. 「バックアップ」で JSON 保存、「復元」で読み込み（別の PC に移す時）

・媒体は「媒体の設定」で追加・色変更・削除できます
・素材が「未着手」の予定は黄色の縁で警告されます
・データはこのブラウザの中（localStorage）にだけ保存され、外部には送信されません
