周年記念動画 ヒアリングシート＆構成案ジェネレーター（無料）
==============================================================
1. index.html をブラウザ（Chrome推奨）で開く
2. 左の項目を選ぶ／入力する（会社名・周年・上映の場・入れたい章・素材・撮影日数・納期・予算感）
3. 右に「ヒアリング内容／構成案（尺配分）／スケジュール目安／費用の目安」の A4 シートが即時に出ます
4. 「PDF で保存 / 印刷」で A4 に。「構成案をテキストでコピー」でメールに貼れます
5. JSON 保存／読み込みで別 PC に持ち運べます

・入力はこのブラウザの中（localStorage）にだけ保存され、外部には送信されません
・費用・スケジュールは目安です。正式なお見積りは相談窓口へ
・「相談窓口」の表記（シート下部）は左パネルで変更できます
