料金表メーカー（製品版）
========================
1. index.html をブラウザ（Chrome推奨）で開く
2. 右で 店名・タイトル・色・税込／税抜 を選ぶ
3. 「＋ 行を追加」でメニューを入力（カテゴリが同じ行は 1 つの見出しにまとまります）
4. 「A4 で印刷 / PDF 保存」で店頭用、「正方形 PNG」で SNS 用（カテゴリごとに 1 枚）

・CSV 保存／読込 で表計算ソフトと行き来できます（列: category, name, note, time, price, first, rec）
・入力はこのブラウザの中（localStorage）にだけ保存され、外部には送信されません
