# BASE 登録チェックリスト（1 回 30 分・10 商品ずつ）

目的: 39 商品を一度にやらず、10 商品ずつ 4 回に分ける。途中で止めても「どこまでやったか」が分かるようにする。

## 0. 準備（初回だけ・5 分）
- [ ] BASE 管理画面 → Apps → **CSV商品管理** を追加（無料）
- [ ] Apps → **デジタルコンテンツ販売** を追加（無料）
- [ ] このフォルダの `items_01.csv`〜`items_04.csv` を手元に保存（GitHub の Raw → 保存。文字コードは UTF-8 BOM 付きで、Excel で開いても崩れない）

## 1. CSV をアップロード（1 ファイル 2 分）
- [ ] CSV商品管理 → 「CSV をアップロード」→ `items_01.csv`
- [ ] エラーが出たら列名を控えて Claude に送る（App の雛形に合わせて作り直す）
- [ ] 商品一覧に 10 商品が「非公開」で増えたことを確認（CSV の公開状態は 1 ＝公開。非公開で入れたい場合は列を 0 にするので言ってください）

## 2. ZIP を付ける（1 商品 2 分 × 10）
各商品の `factory/base/<pack>/zip.txt` に Release の URL と ZIP ファイル名が書いてある。
- [ ] Release ページ → Assets → `<pack>_<日付>.zip` をダウンロード
- [ ] BASE 商品編集 → デジタルコンテンツ販売 → ZIP をアップロード → 保存
- [ ] 10 商品ぶん繰り返す（順番は表示順 = CSV の並び）

## 3. 公開して URL を送る（10 商品 3 分）
- [ ] 商品ページを開き、画像 7 枚・価格 ¥1,980・説明文の「よくある質問」まで表示されているか 1 つだけ確認
- [ ] 10 商品の URL（`https://chaincreate.base.shop/items/…`）をまとめて Claude に貼る → `shop/links.json` に反映され、shop ページの「BASE で購入」が有効になる

## 4. 次の 10 商品へ
- [ ] `items_02.csv` で 1〜3 を繰り返す。`node factory/base_kit.mjs --missing` で未登録パックが減っているか確認できる

## 困ったとき
- CSV の列名が合わない → App の雛形 CSV をダウンロードして Claude に送る
- 画像が表示されない → 画像 URL は GitHub の main ブランチを参照している。ブランチ未マージなら `--ref claude/monetization-tool-rebuild-qp828g` で作り直す
- ZIP が大きい → 1 パック 3〜8MB。BASE の上限（1GB）には余裕あり
