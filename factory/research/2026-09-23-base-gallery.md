# 2026-09-23 リサーチ: BASE 商品ギャラリー画像ジェネレーター（社内ツール #10）

## なぜ作ったか
- 9日間で商品9本が Release されたが BASE 登録はゼロ。登録のボトルネックは「商品画像を用意する手間」（BASE は正方形推奨・複数枚で訴求）
- Release には contact_sheet.jpg（横長）しか無く、そのままだと1枚目が小さく潰れる
- 1パックあたり 7枚（表紙／一覧／縦対応／使い方／同梱物／比較表／FAQ）を、パックを選ぶだけで生成できれば登録は5分で済む

## 仕様
- `apps/base-gallery/index.html`（単一HTML、依存は cdnjs の JSZip のみ）
- telop/designs.js と renderer.js をそのまま読み、各デザインを Canvas で描画 → 1280×1280 に合成。画像アップロード不要
- 比較表は PACKS を自動で並べ、選択中の商品をハイライト。バンドル価格は入力
- PNG 個別 DL／ZIP 一括 DL。DEMO フラグ・listing.md は無し（社内用）
- Playwright で 7枚生成と ZIP ダウンロードを確認（フォントはローカルキャッシュを経由）

## 運用
1. Pages（main マージ後）か、リポジトリをローカルで開いて `apps/base-gallery/` を開く
2. パック選択 → 生成 → ZIP → BASE の商品画像に 01 から順に登録
3. 新パックが増えたら比較表は自動で伸びる（既存商品の比較表画像は差し替え推奨）
