## 作り方（マッキー向けメモ）
- 各 Release の zip を3つダウンロードして1フォルダにまとめ、`テロップメーカー/` は最新パックのもの（designs.js が全パック入り）を1つだけ残して zip にする
- 商品画像は `apps/base-gallery/` で各パックの「表紙」を作り、3枚並べる（比較表画像はセット共通で使える）
- kids / sports / beauty / recruit / fitness が増えたら「キッズ・スポーツ・美容セット」を4つ目に追加
