所要 約40分。上から順に。リンクは PDF 上でクリックできます。詰まったら画面のスクショをチャットに貼ってください。

① main にマージ 3分・最初にやる

販売ページ・アプリ2本・先行パック8本を公開するため。衝突はありません。
  1. ここを開く → github.com/chain-movies/daihon-studio/compare/main...claude/monetization-tool-rebuild-qp828g
  2. 緑の Create pull request → もう一度 Create pull request
  3. Merge pull request → Confirm merge（「Create a merge commit」のまま。Squash は選ばない）
  4. 5分後にここが開けば完了 → chain-movies.github.io/daihon-studio/shop/

② BASE に最初の1本を登録 15分・「配信・ゲーム実況テロップ集」から

(a) ファイルと説明文を取る

  1. Release を開く → github.com/chain-movies/daihon-studio/releases/tag/product-stream-vol1-2026-09-24
  2. 一番下の Assets から stream-vol1_2026-09-24.zip をダウンロード
  3. 同じページの本文（「商品名（BASE/BOOTH用）」から下）を全部コピー

(b) 商品画像を取る

  1. ここを開く（①のマージ後に有効） → chain-movies.github.io/daihon-studio/apps/base-gallery/
  2. パックで「配信 Vol.1」を選ぶ → 生成 → PNG をまとめて ZIP でダウンロード（7枚。01 が表紙）
  3. マージ前なら GitHub 上の生成済み画像でも可 → factory/gallery/stream-vol1

(c) BASE に登録

  1. BASE 管理画面 → admin.thebase.com
  2. 初回だけ: 左メニュー Apps → 「デジタルコンテンツ販売」を検索してインストール（無料）
  3. 左メニュー 商品管理 → 商品を登録
商品名コピーした本文の「商品名（BASE/BOOTH用）」の行 商品画像01_cover から順に 7 枚 価格1980 商品説明コピーした本文の「キャッチ」から下を貼る 販売方法デジタルコンテンツ を選び、(a) の ZIP をアップロード 公開設定公開 にして保存

(d) 商品 URL をチャットに貼る

公開した商品ページの URL（https://〇〇.base.shop/items/12345678 の形）をチャットに貼る → 販売ページの「BASEで購入」ボタンに繋ぎます。
