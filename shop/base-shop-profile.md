# BASE ショップ設定 コピペ用テキスト（chaincreate.base.shop）

BASE 管理画面 → ショップ設定 → 「ショップ説明」「About」に貼る文章と、商品説明の共通フッター、特商法の埋め方メモ。
そのままコピペで使える形にしてあります。社名・住所・電話など実データは各自で入れてください。

---

## 1. ショップ名（候補）

- **Chain-Movies テロップ工房**（推奨。「何屋か」が一目で分かる）
- Chain-Movies 動画素材ストア
- テロップ屋 by Chain-Movies

## 2. ショップ説明（短文・150字前後。トップやSNSカードに出る）

```
テレビ番組風のテロップ素材を、貼るだけで使える透過PNGで販売しています。バラエティ・ニュース・ショート動画・企業VPなどジャンル別に20デザイン×色違い。文字を変えられる「テロップメーカー」付き。商用利用OK・クレジット不要。動画制作会社 Chain-Movies が運営。
```

## 3. About（長文。ショップの「About」ページ）

```
■ Chain-Movies テロップ工房について

Chain-Movies テロップ工房は、動画制作会社 Chain-Movies株式会社が運営する「テロップ素材」の専門ショップです。
テレビ番組でよく見る「あのテロップ」を、Premiere Pro・CapCut・DaVinci Resolve・iMovie などどんな編集ソフトでも「画像を置くだけ」で再現できる透過PNGにしました。

■ 商品の特徴
・1パック = 1ジャンル 20デザイン × 色違い3〜4色（16:9 と 9:16 縦動画の両方を収録）
・文字なしの「帯・ボックスのみ」PNG も同梱。自分の文字を載せて使えます
・ブラウザで動く「テロップメーカー」付き。好きな文字で同じデザインを書き出せます。台本を貼れば全行分を一括書き出し
・Premiere Pro で同じ見た目を作るための設定値（RECIPE.txt）も同梱

■ ライセンス
・商用利用OK、クレジット表記不要（YouTube・広告・企業VP・結婚式映像などに使えます）
・素材そのものの再配布・転売・二次配布、素材集としての再パッケージは禁止
・特定の番組・局のロゴやデザインを複製したものではなく、ジャンルの「雰囲気」を再現した汎用デザインです

■ ご購入後の流れ
ご購入後、BASE のマイページから ZIP ファイルをダウンロードできます。解凍して、編集ソフトに PNG を読み込むだけです。
デジタル商品のため、返品・返金には対応できません。ご不明点は購入前にメッセージでお問い合わせください。

■ 新作
毎日1パックずつ新ジャンルを追加しています。欲しいジャンルがあればメッセージで教えてください。制作の参考にします。

■ 運営
Chain-Movies株式会社（動画制作・編集）
テロップ制作の現場で「毎回ゼロから作るのが面倒」だった自分たちのために作った素材を、そのまま商品化しました。
```
