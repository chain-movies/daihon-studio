# FV背景動画（E案「光のリボンが渦を巻いて字になる」）

絵コンテPDF（E案）を元に生成AIで制作したHPファーストビュー用の背景動画。
キャッチコピー・ボタンは含まず、背景（富士・湖面・朝日・金の「誉」）のみ。

## 本命のタイムライン（絵コンテ対応）

| カット | 絵コンテ | 動画 |
| --- | --- | --- |
| C1 夜明け前・静止 | 0.00–1.60 | 0.0–1.6 |
| C2 太陽が出て光の筆が走る | 1.60–2.40 | 1.6–2.1 |
| C3 渦を巻き結像 | 2.40–3.30 | 2.1–2.8 |
| C4 金の「誉」完成・静止 | 3.30–4.60 | 2.8–4.63 |

生成素材の冒頭0.4秒をトリムし、太陽の出を1.6秒に合わせた。
渦のフェーズは絵コンテの推奨どおり短め。

## 「誉」の光り方（本命）

| 時間 | 動き |
| --- | --- |
| 2.1–2.5 | 白い光のリボンが収束し、白い筆文字として現れる |
| 2.5–2.62 | 白金色に輝く「誉」に変わる（ここがピーク） |
| 2.62–4.63 | ピークの光った状態を保持。周期2.4秒・最大+5%のごく弱い呼吸で生きた画にしている |

マットな金に落ち着くカットは使わず、光った「誉」が最後の絵になる。
旧版（`_settle`）は落ち着いた金に後付けグローを重ねたもの。

## 実装メモ

- 画は上へ4%オフセット（絵コンテ指示）: `object-position: 50% 46%` などで対応。
- 終了後は最終フレームで静止させる（`loop`なし、`autoplay muted playsinline`）。
- 生成: 静止画 Nano Banana Pro、動画 Seedance 2.5（omni_reference, start/end frame指定）。
